# DexGEM Benchmark 在线总览

## 入口与范围

唯一规范入口：<https://dex-gem.ai/artifacts/roadmap/benchmarks/overview.html>

- 用于了解 DexGEM Benchmark 全貌、定位项目相关仓库，以及为入门、规划和跨项目协调补齐上下文。
- 本技能只指导读取与分析；不自动修改仓库、部署、任命或调整负责人关系。
- 不维护静态项目目录、仓库清单或同步副本；每次按任务回到官方页面读取。

## 按需读取

1. 用 `web_fetch` 打开入口；需浏览器渲染时先读 `agent-browser` 技能，再使用浏览器。确认实际读到正文，而非登录页、错误页或空壳。
2. 读取总览及当前 BENCHMARK 导航，按任务发现并跟随相关项目详情链接；不沿用记忆中的分类、数量或旧链接作为当前清单。
3. 阅读相关详情页，打开页面实际给出的仓库链接，按需读取仓库说明；保留真实 URL，不凭项目简称拼接仓库地址。缺失或失效链接明确标注。
4. 分清项目、独立仓库、子模块、仓库内目录、数据/产物与能力节点；页面未证明的映射或子模块关系标为未核验，不从图形邻接推断。
5. 区分源文描述的目标架构、计划与已实现/已部署状态；只按实际证据陈述达成状态，不把依赖图当作全部可用。

## 访问与证据边界

- 仅使用合法且已获授权的现有登录会话。遇飞书登录/SSO 门禁且无可用授权时，说明正文未读及缺失范围，请求合法访问或用户提供当前内容；不绕过门禁、猜凭据。
- 不把旧记忆、摘要、源码摘要或历史快照冒充最新在线正文。用户明确提供源码副本时，单独标明其版本、来源及证据边界，不静默替代在线读取。
- 在线访问缺失不阻塞已有明确范围的独立工作；仅暂缓依赖未读内容的断言或跨项目决策。
- 临时任务笔记可留存当次观察，但不是以后查询的当前事实源；不生成或安装快照目录。

## 输出与协作

- 只输出当前任务需要的项目目标、仓库映射、相关依赖和缺口，附实际读取的来源链接、读取时间（含时区）及未核验项。
- 分开标明页面事实、推断与未知；目标和达成状态分别陈述，来源冲突先回源核对。
- 技术依赖不代表人员汇报链、写权限或实施就绪；查负责人、任命、交接、调整/重置关系时，另读 `responsibility-registry`，以其当前登记与授权为准。本技能不写入其数据。
